## 실제 시장·모델 연결

`jev-tournament-7d-local-v2`는 2026-10-04 09:51:43.862654 KST에 시작했고 2026-10-11 같은 시각에 종료합니다. 실제 최초 자산 스냅샷 9개의 최소·최대 평가액이 모두 정확히 1,000,000원이었습니다. BTC/KRW와 ETH/KRW 데이터를 공유하고 6개 Jev 질문 세트가 각각 `tev1:0.8b`의 native 판단 API에서 정상 응답했습니다.

시작 전 6개 스타일의 요청당 지연은 약 5.8–6.6초였습니다. 동시 요청 1개로 분당 12개 요청을 모두 50초 예산 안에 완료할 수 없으므로 실제 마감 누락이 발생합니다. 순서를 회전하고 누락·지연을 기록하며 과거 가격으로 소급 체결하지 않습니다. 이 성능 제한도 대회 결과의 일부입니다.

초기 연결 점검 대회 v1은 입력 길이·시간 초과를 확인해 일시정지한 채 보존했습니다. 공통 상태 숫자 압축을 사용하는 v2는 별도 ID이며 시작 후 질문·전략·threshold를 변경하지 않았습니다.
